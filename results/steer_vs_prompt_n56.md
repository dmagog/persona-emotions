# Стиринг vs промптинг — baseline (W7), gemma-2-2b, судья n=56 + CI

Главный честный контроль: даёт ли активационный стиринг что-то сверх простой
инструкции «пиши как человек, чувствующий <эмоцию>»? Обе матрицы специфичности
оценены тем же LLM-судьёй на 56 промптах/условие, bootstrap 95% CI.
`emotion/steer_specificity.py --prompt-baseline` → `judge_specificity` → `bootstrap_ci`.

## Диагональ Δ vs baseline [95% CI]

| эмоция | стиринг (SAE-фичи) | промптинг |
|--------|-------------------:|----------:|
| anger   | +36 [25, 47] | **+40 [31, 49]** |
| disgust | +29 [19, 40] | **+37 [27, 47]** |
| fear    | +48 [36, 60] | +48 [38, 58] |
| guilt   | +49 [37, 60] | **+58 [48, 68]** |
| joy     | +34 [20, 48] | **+57 [45, 68]** |
| sadness | +44 [33, 54] | +43 [33, 52] |
| shame   | **+57 [46, 67]** | +45 [34, 56] |
| sadness leakage | +28 [20, 37] | **+18 [9, 27]** |
| target = argmax | 6/7 | **7/7** |

## Вывод

- **Простой промптинг не уступает стирингу, а чаще превосходит:** сильнее по
  диагонали у 5/7 эмоций, **специфичнее** (меньше протечки в sadness: +18 vs +28),
  и target=argmax у всех 7 (против 6/7 у стиринга).
- Значит на задаче «навести конкретную эмоцию в нейтральном промпте» активационный
  стиринг через SAE-фичи **не даёт выигрыша над инструкцией** — в нашей постановке
  даже немного уступает по специфичности.
- Это очерчивает реальную границу работы. Отличительная ценность стиринга
  (композиционность/векторная алгебра, управление без промпта, при противоречивой
  инструкции) здесь **не проверялась** — это и есть настоящее направление, где
  стиринг мог бы обойти промптинг (Фаза 4).
- Самый крепкий новый результат остаётся методологическим (контраст активаций SAE
  расщепляет эмоции там, где проекция нет).
